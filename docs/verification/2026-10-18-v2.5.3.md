# 2.5.3 紧急热修复验收

基线为远端 main `8c2c0f1e3a1caf5cb682704a576d36a449a6780d`，单独分支 `hotfix/v2.5.3`。此次只移除 2.5.2 新增的 EAC 60 秒无有效输出截止，并同步 2.5.3 版本和安装文档；没有带入其他尚待终审的本地功能修复。

## 改动

- 删除 `progressTimeoutMs` 默认值及 Adapter 的进展定时器，不再因静默排队、心跳、用量帧或输出间隙产生 `NO_PROGRESS`。
- 忽略旧配置中的 `progressTimeoutMs`。保留调用者取消、实际传输断线处理和既有恢复策略。
- 替换原先“应在进展截止失败”的回归，验证等待后正常完成、同一物理请求不被重复提交、链路不因静默擅自切换；增加默认 60 秒定时器未创建的回归。
- OpenCode 的 `src/upstream.js`、请求传输、探测规则与渠道指纹源码未改动。匿名上游准入拒绝不属于本次修复范围。
- 本机真实升级日志复现 `packages/desktop/src-tauri/target` 被备份到 C 盘并触发 `ENOSPC`；增加顶层 `packages` 排除，升级、清理与回滚都不得遍历或复制独立产品树，原编译缓存保留在 D 盘。
